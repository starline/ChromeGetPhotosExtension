# GetPhotos Chrome Extension

Документация по установке и использованию расширения, которое собирает ссылки на изображения с активной страницы и отображает их во всплывающем окне.

## Требования
- Google Chrome 88+ или другой Chromium-браузер с поддержкой Manifest V3.
- Права на включение режима разработчика для установки распакованных расширений.

## Установка
1. Склонируйте репозиторий или скачайте архив с кодом.
2. Откройте `chrome://extensions/` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и укажите папку проекта (`GetPhotos`).
4. Убедитесь, что расширение появилось в списке и включено.

## Обновление
- После внесения изменений в код нажмите кнопку **Обновить** на странице расширений, чтобы перезагрузить GetPhotos.

## Использование
1. Откройте страницу, где нужно собрать ссылки на изображения.
2. Нажмите на иконку GetPhotos в панели расширений (закрепите её при необходимости).
3. В появившемся попапе нажмите **Открыть** → **Собрать ссылки**. Расширение:
    - выполнит `chrome.scripting.executeScript` на активной вкладке;
    - найдёт источники `<img>` и прямые ссылки на файлы изображений;
    - отобразит уникальные ссылки списком или покажет сообщение, если изображений нет.
4. Закройте диалог, чтобы очистить предыдущий результат.

## Разрешения и безопасность
- `activeTab`, `tabs` — для чтения текущей вкладки и управления всплывающим окном.
- `scripting` — для безопасного выполнения функции сбора ссылок на странице.

## Структура
- `manifest.json` — конфигурация расширения.
- `src/popup.html`, `src/popup.js`, `src/popup.css` — интерфейс и логика всплывающего окна.
- `assets/` — иконки и дополнительные стили (если добавлены).
