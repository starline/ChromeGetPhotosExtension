# GetPhotos — Chrome Extension

Расширение Manifest V3, которое вытягивает все ссылки на изображения с любой открытой страницы (src у `<img>` и ссылки с расширениями изображений), показывает их списком и убирает дубликаты. Можно сразу отсечь картинки ниже нужной ширины и быстро копировать найденные ссылки.

## Требования
- Google Chrome 88+ или другой Chromium-браузер с поддержкой Manifest V3.
- Доступ к страницам, с которых нужно собрать ссылки (расширение работает в активной вкладке).

## Установка
1. Скачайте или клонируйте репозиторий в удобную папку, например `~/GetPhotos`.
2. Откройте `chrome://extensions/`, включите `Режим разработчика`.
3. Нажмите «Загрузить распакованное» и укажите корень проекта (`GetPhotos`).
4. Закрепите иконку расширения на панели, чтобы быстро запускать сборщик.

## Использование
1. Откройте страницу, с которой хотите снять ссылки на изображения.
2. Нажмите на иконку GetPhotos — появится боковая панель с фильтром по минимальной ширине и кнопкой «Собрать изображения».
3. Укажите минимальную ширину (опционально) и кликните «Собрать изображения»: расширение просканирует `<img>` и ссылки на файлы изображений, выведет список без повторов и покажет размеры/вес.
4. Нажмите «Копировать» возле ссылки, чтобы отправить URL в буфер обмена, или «Открыть», чтобы открыть картинку в новой вкладке.
5. Чтобы закрыть панель, нажмите крестик.

## Структура проекта
- `manifest.json` — манифест MV3 (permissions: `activeTab`, `tabs`, `scripting`).
- `src/background.js` — сервис-воркер, встраивает боковую панель на странице.
- `templates/panel.html`, `assets/panel.css` — разметка и стили боковой панели.
- `assets/` — иконки и стили, используемые в шаблонах.

## Разработка и отладка
- После правок в файлах нажмите «Обновить» на `chrome://extensions/`, чтобы перезагрузить сборку.
- Логи сервис-воркера смотрите в DevTools расширений (`Service Worker` → `Inspect`).
- Встроенная панель использует `chrome.scripting.executeScript` и `Shadow DOM`, поэтому проще тестировать прямо на реальных страницах с изображениями.
